행동 로그 설계 근거

어떤 행동을, 왜 그만큼의 무게로 세는가

화장품 커머스에서 수집하는 행동 이벤트 35종의 가중치와 그 근거다. 값은 전부 상품 상세 조회 1.0을 기준선으로 상대 배치했고, 외부 조사로 뒷받침되는 것과 우리가 정한 값을 구분해 표기했다.

기준선
product_view = 1.0 · 절대값이 아니라 이 값에 대한 상대 위치가 의미다
범위
−2.0 … 4.0 · 감점은 별도 벡터로 빼고, 분모에 음수를 넣지 않는다
전제
PC 전용 · 포인터 이벤트의 수집률이 균일해 사용자 간 비교가 가능하다
근거 표기
공개 출처 있음 · 논문 학술 · 관행 업계 · 추정 우리가 정함

값을 정할 때 지킨 규칙

7 rules
  1. 01기준선에 대한 상대 배치. product_view = 1.0을 놓고 나머지를 그 위아래로 잡는다. 절대값 자체에는 의미를 두지 않는다.
  2. 02노출은 0. 사용자의 의지가 아닌 것에 선호를 주지 않는다. 대신 클릭률의 분모로 쓴다.
  3. 03감점은 별도 벡터. 사용자 벡터의 분모에 음수를 넣으면 0에 가까워질 수 있다. 긍정·부정을 따로 만들어 최종 점수에서 뺀다.
  4. 040.3짜리는 단독 판정 금지. scroll_pause, hover_dwell은 다른 신호와 함께일 때만 의미를 준다. GA4의 참여 판정이 OR 조건인 것과 같은 이유다.
  5. 05같은 행동도 대상에 따라 다르다. content_kind와 section_id를 가중치 조회 키에 포함한다. 성분에 머문 1초와 히어로에 머문 1초는 다르다.
  6. 06이중 가산 금지. 한 행동을 두 이벤트가 세면 한쪽을 0으로 둔다. section_view가 0인 이유다.
  7. 07추정은 추정이라고 쓴다. 어떤 플랫폼도 자사 가중치를 공개하지 않는다. 남의 값을 빌려 온 척하지 않는다.
수치는 가설이므로 Ablation으로 검증한다 — 감점 축 제거, 암묵 신호 제거, 섹션 가중 균일화, 노출 가중 부여. 평가는 합성 로그가 아니라 실제 리뷰 Holdout으로 한다.
