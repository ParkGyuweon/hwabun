## 0. 진단 — 지금 덱이 잘 하는 것과 빠진 것

**잘 하는 것.** 시장 배경(3~6장), "왜 모여야 하는가"(7장), 리테일 미디어 구조 차용(8장),
분산 처리의 이유(14장), 5초 규칙 진단 한 줄(15장)은 논리가 서 있다. 이건 건드리지 않는다.

**빠진 것.** 덱은 "인프라를 나눠 쓴다"까지 말하고 **"그래서 무슨 인사이트를 어떻게 뽑아
어떻게 돌려주나"** 가 없다. 15장 한 장에 벤치마크·고객군·콘텐츠가 키워드로만 있고,
우리가 정리한 세 질문·세 층·증명 장치·구매/설문/재구매·트렌드 피드가 전부 없다.
게다가 몇 곳은 **지금 계획과 반대로** 적혀 있다.

## 1. 바꾸는 장

### 12장 — 이벤트 계약과 행동 가중치

- 분류를 `intent` 용어로: exposure → interest → comparison → validation → conversion, friction은 옆에
- "구매 이벤트 제외" 문장 삭제. 대신: **"구매·구매 이유 설문·재구매를 다음 단계로 활성화한다.
  계약에 이미 Planned로 예약되어 있다."**
- 공통 속성에 `brand_id` 추가 예정 표기
- 숫자: 36종, 104,976가지

### 13장 — Persona

- 하단 경계 문장은 유지. 그 위에 한 줄 추가:
  **"페르소나의 피부 속성과 리뷰 이력은 실측이다. 상품 × 피부 구매 성향(친화도)과 브랜드
  재구매 신호는 여기서 나오고, 대시보드의 '누구에게 팔아야 하나'·'다음 제품은'의 근거가 된다."**
- 표기 주의: "효능"이 아니라 "구매 성향". "예측"이 아니라 "리뷰에서 관찰된 성향"

### 15장 — 진단 한 줄과 Dashboard → **"세 질문"** 으로 재구성

지금은 키워드 4개. 이걸 **세 질문**으로 바꾼다. 각 질문에 대표 인사이트 1개와 첫 줄 문장 1개.

| 질문 | 대표 인사이트 | 첫 줄 예시 |
|---|---|---|
| 무엇을 써야 팔리나 | 성분 갭 (찾는데 없는 성분) | "나이아신아마이드를 긁어가는데 내 라인엔 없다" |
| 누구에게 팔아야 하나 | 예측 vs 실측 (친화도 lift ↔ 실제 담기율) | "예측은 건성인데 실제로 담는 건 지성 고객이다" |
| 다음 제품은 | 고민 커버 격자 + 라인 재구매 | "다크서클 × 건성 칸이 비어 있다" |

세 질문 아래에 **"모여야만 나오는 것" 여섯 갈래**를 한 줄씩 둔다 (insight-catalog 참고):
표본 빌리기 · 내 위치(같은 성분 상품끼리 비교) · 시장 공백(아무 브랜드에도 없는 성분) ·
고객 이동 경로(대신 산 상품의 특징, 익명) · 함께 실험(진열·섹션 위치) · 첫날부터(콜드스타트 진단).
이것이 7장 세 질문의 답이고 8장 "리테일 미디어 구조"의 실제 산출물이다.

"일반 웹 분석 도구가 멈추는 곳 / HWABUN이 더 하는 것" 대비는 유지. 단 한 줄 추가:
**"화장품을 신발로 바꿔도 말이 되면 그건 일반 도구의 지표다. 우리 축은 성분 × 고민 × 피부."**

### 21장 Q&A — Q6 교체, Q7·Q8 추가

- Q6(왜 구매 제외) → **"구매를 어떻게 넣나"**: 결제 연동 없이 테스트 주문 번호를 발급하고
  `purchase`와 구매 이유 설문을 잇는다. 재구매는 사용자 단위 구매 fact에서 잰다.
- Q7 **"합성 데이터인데 인사이트가 의미 있나"**: 행동은 실제 리뷰 이력·피부 정보에서,
  재구매는 중복 리뷰에서, 설문은 행동과 같은 원인(스타일 축)에서 나온다. 값이 아니라
  **지표가 만들어지는 구조**를 증명한다.
- Q8 **"성분이 핵심인데 추천에는 왜 약한가"**: 성분의 재구매 예측력은 1.02x로 낮다.
  벡터에 0.27로 들어가 있고 제거를 검토 중. 성분의 자리는 콘텐츠 결정, 추천은 브랜드(6.08x)·고민이 주도.
  ("추천에 안 들어간다"고 말하지 않는다.)

## 2. 신설하는 장 (3장, 15장 뒤에)

### 신설 A — "무엇을 나누고 무엇을 지키나" (공유 3층)

```
C  커먼즈     성분 관심 추세 · 피부 × 콘텐츠 · 진열 효과 · 트렌드      모두 같은 것을 본다
B  벤치마크   전환율·열람률의 코호트 중앙값·25·75 + 내 위치            비율만 · 해시 · 5개 미만 억제
A  내부자산   원가·매출·상품 단위 건수·고객 로그                     브랜드 밖으로 안 나간다
```

- 규칙은 8개 중 3개만: 브랜드 5개 미만 억제(Triple Whale), 분모 200 미만 흐림, 한 브랜드 50% 초과 억제
- 관행 근거 한 줄: Shopify·Triple Whale 벤치마크, 캐시노트 170만 사업장 "같은 업종 비교"
- 한국 맥락 한 줄: 특가 원가 노출·주문내역 영업비밀 우려(유통 데이터 전송요구권 논쟁)
- **"공유하는 것은 비율이고, 지키는 것은 절대치다."**

기존 8장의 "격리 — 집계된 분포뿐" 과 9장의 "공유하지 않는 것" 은 이 장을 가리키도록 한 줄로 줄인다.

### 신설 B — "근거 있다는 것을 어떻게 보이나" (증명 장치 3개)

| 장치 | 무엇을 증명 | 화면 |
|---|---|---|
| 선언 vs 추론 | 행동 추론이 맞는다 — 구매 이유 설문과 콘텐츠 체류의 일치율 N% | 2×2 |
| 예측 vs 실측 | 친화도 모델이 화면에서 검증된다 | 상품별 두 열 |
| 재구매의 출처 | 지어낸 값이 아니다 — 중복 리뷰 → 재구매, 같은 브랜드 30.6%(200개·55브랜드 조건) | 배지 |

이 장이 "합성 데이터 아니냐" 질문을 발표 안에서 미리 답한다.

### 신설 C — "시장에서 배우기" (커먼즈 + 트렌드)

- 성분 관심 지수 주간 추세(2주 연속 상승 표시) + 글로벌 트렌드 피드가 같은 성분 사전에 매핑
- "PDRN 글로벌 상승 — 우리 몰 관심 +N%, 코호트 12곳 중 보유 2곳"
- 구조 한 줄: 매일 아침 배치 1회, Claude API + web_search, 결과는 정적 JSON, **백엔드 0줄, 월 $7 미만**
- 실효성 기준 한 줄: 커먼즈 인사이트는 1인 창업자가 할 수 있는 행동 넷(문구·진열·다음 제품·타깃) 중
  하나로 곧장 이어져야 화면에 올린다

## 5. 정직하게 남길 문장 (13장 또는 신설 B 하단)

- 어휘와 페르소나는 세포라 미국 데이터. 국내 축은 사전 교체로 들어가는 구조를 보인다
- 성분은 예측력이 낮아 콘텐츠 결정에 주로 쓴다 (벡터에는 남아 있다)
- 친화도는 효능이 아니라 구매 성향
- 30.6%는 200개·55브랜드 조건의 값
- 결제는 테스트 주문, 실사용자 재구매는 계정 이후
