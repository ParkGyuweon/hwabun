# 제출물 안내

이 폴더는 GitLab 저장소를 클론한 뒤 HWABUN을 다시 빌드하고 배포하거나 시연하는 데 필요한 자료입니다. 기준 소스는 제출 시점의 GitLab 커밋이며, 이 폴더에 소스코드를 별도로 복사하지 않습니다.

| 요구사항 | 파일 |
| --- | --- |
| 1. 포팅 매뉴얼: 빌드와 배포, 버전, 환경 변수, DB 설정 | [1_포팅_매뉴얼.md](1_포팅_매뉴얼.md) |
| 2. 외부 서비스 정보: 가입과 연동 | [2_외부_서비스_정보.md](2_외부_서비스_정보.md) |
| 3. 데이터베이스 덤프: 최신본과 복원 안내 | [3_데이터베이스_덤프.md](3_데이터베이스_덤프.md), `db/` |
| 4. 시연 시나리오: 화면별 시연 순서 | [4_시연_시나리오.md](4_시연_시나리오.md) |

비밀번호, 개인키, API Secret, 실제 운영 `.env`는 포함하지 않습니다. DB 덤프에는 회원 데이터가 들어갈 수 있으므로 전달 대상과 보관 권한을 제한하세요. 덤프의 기준 시각과 검증 값은 [3_데이터베이스_덤프.md](3_데이터베이스_덤프.md)에 적습니다.
